# Портфолио Виктории

Статичный сайт без сборки и дополнительных программ. Все реальные фотографии и видео находятся в папке `images`.

## Как открыть на Mac

Дважды нажмите на `index.html` — сайт откроется в браузере. После изменений обновите страницу сочетанием `Command + R`.

## Как добавить новую работу

1. Положите изображение или видео в папку `images`. Лучше использовать понятное имя латиницей без пробелов, например `cosmetics-cover.png`.
2. Откройте `script.js`.
3. В самом начале файла найдите список `const projects = [ ... ]`.
4. Скопируйте один готовый объект проекта, вставьте его перед закрывающей скобкой списка и замените данные.

Пример:

```js
{
  folder: "ai-video",
  title: "Название нового проекта",
  category: "AI-видео",
  description: "Короткое описание для карточки.",
  media: [
    "images/new-cover.png",
    "images/new-video.mp4"
  ],
  task: "Какая задача стояла перед проектом.",
  result: "Что было разработано."
},
```

Первый файл в `media` становится обложкой. Остальные изображения и видео показываются внутри кейса в указанном порядке. Файлы MP4 сайт распознаёт автоматически и выводит с кнопками управления.

Доступные значения `folder`:

- `marketplace` — Маркетплейсы
- `ai-video` — AI-видео
- `ai-cartoons` — AI-мультфильмы
- `business` — Дизайн для бизнеса
- `social` — Дизайн соцсетей
- `ai-visual` — AI-визуал

Если нужна новая папка, добавьте строку в список `const folders = [ ... ]` ниже списка проектов, а затем используйте её `id` в поле `folder` проекта.

## Где менять основные данные

- Текст первого экрана, блок «Обо мне» и контакты — в `index.html`.
- Работы, порядок папок, названия и описания — в `script.js`.
- Цвета, размеры, отступы и мобильная версия — в `style.css`.
